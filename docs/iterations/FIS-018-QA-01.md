# FIS-018 QA-01 — Release Candidate Hardening

**Status: DONE**

FIS-018 is a focused release-readiness iteration. It adds regression coverage
and targeted hardening without changing the existing workflow architecture.

Scope includes mock-based workflow and case handoffs; fail-closed safety and
path checks; subprocess ownership, argument arrays, controlled working
directories, bounded waits, and bounded ffprobe metadata; cancellation and
partial-artifact checks; atomic-write interruption tests; report consistency;
Safe Review Mode and CLI/GUI smoke coverage; release packaging and dependency
notice checks.

The project remains version `0.1.0`. Optional TSK, PhotoRec, FFmpeg/ffprobe,
libewf, GNU ddrescue, model weights, and NudeNet runtime are not bundled. The
standalone tests do not require real devices, models, or forensic tools.

Known limitations are summarized in the README and forensic principles:
SSD TRIM and device behavior can prevent recovery; video analysis is sampled;
models can produce false positives and false negatives; optional tools and
decoders may be absent; no hardware write blocker is supplied; recovery is not
guaranteed; human review is required.

Validation completed: 291 tests passed, 1 skipped, and 3 deselected; Ruff and
pip check passed; `git diff --check` passed. Wheel and source distribution
builds succeeded, and the wheel passed CLI version/help smoke checks in a clean
virtual environment.
